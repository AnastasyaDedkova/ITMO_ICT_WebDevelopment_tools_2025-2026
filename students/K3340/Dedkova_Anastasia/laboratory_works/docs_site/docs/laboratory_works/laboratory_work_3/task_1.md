# Подзадача 1. Упаковка FastAPI-приложения, базы данных и парсера в Docker

## Постановка задачи

В первой подзадаче требовалось упаковать систему в Docker.  
Нужно было организовать запуск FastAPI-приложения, PostgreSQL, парсера и дополнительных сервисов в контейнерах.

## Что реализовано

Для решения этой задачи были созданы:

- `docker-compose.yml` — файл оркестрации сервисов;
- `app/Dockerfile` — Dockerfile для FastAPI API;
- `parser/Dockerfile` — Dockerfile для parser-сервиса и Celery.

## Структура сервисов

Через `docker-compose.yml` поднимаются следующие сервисы:

- `db` — база данных PostgreSQL;
- `redis` — Redis для очереди задач;
- `parser` — отдельный сервис парсинга;
- `worker` — Celery worker;
- `beat` — Celery Beat;
- `api` — FastAPI API.

Такое разделение нужно для того, чтобы каждый компонент системы выполнял свою роль:

- API принимает запросы от пользователя;
- parser отвечает за получение и разбор страницы;
- PostgreSQL хранит данные;
- Redis используется как брокер очереди;
- worker выполняет фоновые задачи;
- beat запускает периодические задачи.

## Dockerfile для API

В `app/Dockerfile` используется базовый образ `python:3.12-slim`.

Основные шаги сборки:

1. задаётся рабочая директория `/app`;
2. копируется `requirements.txt`;
3. устанавливаются зависимости;
4. копируется исходный код;
5. приложение запускается через `uvicorn`.

## Dockerfile для parser

В `parser/Dockerfile` также используется `python:3.12-slim`, но дополнительно устанавливаются системные зависимости:

- `gcc`
- `libpq-dev`

Они нужны для корректной работы зависимостей PostgreSQL, в частности `psycopg2`.

## Почему Docker удобен в этой работе

Docker позволяет запустить все компоненты проекта в одинаковой среде и не зависеть от локальной настройки системы.  
Это особенно важно, когда в проекте одновременно используются FastAPI, PostgreSQL, Redis и Celery.

## Вывод

В первой подзадаче система была успешно упакована в Docker.  
Все основные сервисы проекта запускаются через `docker-compose.yml`, а API и parser имеют собственные Dockerfile.
